build-tools - a skill for building tools
========================================

WHAT IT IS
A skill that helps build any tool or app idea, online or offline: Magisk/KernelSU modules, scripts, command-line tools, web tools.

HOW TO INSTALL
Copy the build-tools folder (it contains SKILL.md) into your skills folder.

RULES
- It must work 100%, or it is not shipped.
- Use as few tokens as possible.
- Credit the original developer and the new developer.
- The goal is working output, not padding.

WHAT IT PRODUCES
- README.md  (for GitHub)
- README.txt (this file, for people on the device)
- AI.md      (for AI models)
- CHANGELOG.md
